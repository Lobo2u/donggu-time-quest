# 조사 자료

지역 조사, 유사 서비스 조사, 현장 답사, 사용자 인터뷰와 문제 발굴 기록을 모읍니다. 현재 문제 정의와 장소·시대 구성은 조사 중이며 확정되지 않았습니다. 모든 팀원이 함께 조사합니다.

## 기록 방법

- 파일명 예시: `2026-10-08-주제-작성자.md`
- 조사 질문 → 확인한 자료 → 관찰 또는 인터뷰 → 해석 → 남은 질문 순으로 기록합니다.
- 사실, 인터뷰 발언, 팀의 해석·아이디어를 구분합니다.
- 자료마다 제목, 작성·발행 기관, 원문 URL, 발행일(확인 가능할 때), 확인일, 뒷받침하는 주장과 인용 위치를 기록합니다.
- 사진·이미지는 촬영자 또는 소장 기관, 원문 URL, 촬영·제작 시점, 이용 조건을 기록합니다. 공개 웹에 있다는 이유만으로 재사용 가능하다고 판단하지 않습니다.
- 인터뷰 참여자의 이름·연락처·얼굴 등 개인정보는 동의 없이 저장소에 올리지 않습니다. 개인을 알아볼 수 없는 요약을 우선합니다.
- 현장 답사 전 운영 시간, 출입 가능 구역, 촬영 가능 여부, 이동 거리와 보행 안전을 확인합니다.

## 유사 서비스 조사 후보

아래 명칭은 사용자가 제안한 **미검증 조사 단서**입니다. 현재 운영 여부, 기능, 성과를 확인한 목록이 아니며 우수 사례라는 평가도 아닙니다. 공식 자료와 직접 사용 결과를 확인한 뒤 비교합니다.

- 스마트관광도시
- 터치수원
- 인천e지
- 단양갈래
- 비짓제주

비교 질문: 누가 사용하는가, 해결하려는 불편은 무엇인가, 현장 방문을 어떻게 유도하는가, 지도·미션·기록은 어떻게 연결되는가, 정보 출처와 접근성은 어떻게 제공하는가?

- 안동 하회마을

- 수원화성 행궁동
- 담양

- 부산 적산가옥

명칭·소재지·역사·운영 현황을 사실로 전제하지 않습니다. 특히 포괄적이거나 해석이 필요한 표현은 실제 조사 대상을 특정한 뒤 출처의 공식 명칭을 확인합니다.

## 다음 조사에서 결정할 것

1. 사용자 인터뷰와 현장 관찰로 해결할 문제를 좁힙니다.
2. 공식·공공 자료, 박물관·기록관·문화유산 자료 등 원문을 확인합니다. 출처 간 설명이 다르면 차이를 기록합니다.
3. 출처가 확보되고 안전하게 걸어서 연결할 수 있는 장소 2~3곳을 검토합니다.
4. 시대 구분이 실제 자료와 맞는지 확인합니다. 모든 시대를 억지로 채우지 않습니다.
5. 검증된 주장과 이용 가능한 이미지가 준비된 내용만 `docs/quests/`의 퀘스트 초안으로 옮깁니다.
