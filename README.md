# 동구 TIME QUEST

2026 대전 로컬창업 해커톤 출품작입니다. 대전 동구의 장소를 직접 걸어 다니며 '시간 친구'를 수집하는 모바일 웹 게임으로, 지역 관광객 유치를 목표로 합니다.

현재는 **소제동·중앙시장·한의약거리·인동시장 4개 장소의 게임 플레이 루프가 구현된 상태**입니다. 시연 모드로 GPS·QR 없이도 전체 흐름을 체험할 수 있습니다.

---

## 1. 프로젝트 방향

### 해결하려는 문제

대전 동구는 역사·문화 자산이 풍부하지만 외지 방문객이 찾아오는 경우는 적습니다. 안내 콘텐츠는 있어도 '왜 직접 가야 하는지'의 동기가 부족합니다. 게임의 수집·성장 구조를 통해 장소 방문 자체를 목적으로 만드는 것이 이 프로젝트의 핵심입니다.

### 핵심 콘셉트

각 장소에는 그 분위기와 역사를 모티브로 한 '시간 친구'가 있습니다. 플레이어는 장소에서 미션을 해결해 시간 친구를 동료로 맞이하고, 현장 QR을 스캔하면 친구가 각성해 능력이 강화됩니다. 각성 순간은 SNS 공유 카드로 남길 수 있어 방문 인증이 됩니다.

```
온라인 플레이  →  시간 친구 획득 (기본 능력)
현장 QR 스캔  →  각성 (강화 능력 + 왕관) + 방문 인증 카드
```

### 창작과 사실의 구분

게임 스토리·캐릭터·미션 시나리오는 모두 창작입니다. 실제 장소 정보(위치, 운영 형태 등)는 화면에서 창작 시나리오와 별도로 표기합니다. 확인되지 않은 역사를 사실처럼 제시하지 않습니다.

## 2. 구현된 기능

### 게임 플레이 흐름

1. **웰컴 화면** — 탐험 동반자 선택 (마중이·중앙이), 시연 모드 안내
2. **탐험 지도** — 장소별 잠금 해제 상태, 현장 각성 여부(⭐), 시간 조각 수
3. **장소 도착** — 창작 시나리오 4단계 열람, GPS/시연 모드 도착 확인, **QR 체크인 배너**
4. **미니게임** — 장소마다 다른 방식
   - 소제동: 카드 뒤집기 기억 맞추기 (3쌍)
   - 중앙시장: 아이템 순서 암기 후 재현
   - 한의약거리: 3×3 빛 패턴 3라운드
   - 인동시장: 사건 타임라인 순서 정렬
5. **시간 친구 만나기** — 등장 연출, 3단계 교감 (성격 기반 정답, 무작위 없음)
6. **보상 화면** — 버디 획득, XP·시간 조각, 다음 장소 해금
7. **QR 스캔** — jsQR 카메라 스캔 또는 시연용 코드 직접 입력
8. **각성 연출** — 충전→폭발→왕관 달린 버디 공개 + 능력 강화 표시
9. **방문 공유 카드** — SNS 공유 / 캡처 가능한 인증 카드 (Web Share API)
10. **기억 조각 도감** — 획득/미획득 시간 친구, 각성 상태
11. **동료 상세** — 능력, 레벨, XP, 연결 장소
12. **내 탐험 기록** — 통계, 미션 목록, 시연 초기화

### 시간 친구 (창작 캐릭터)

| 이름 | 장소 | 색상 | 각성 능력 |
|------|------|------|-----------|
| 소조 | 소제동 | 청록 | 카드 2장 공개 |
| 중자 | 중앙시장 | 오렌지 | 1·2번째 아이템 힌트 |
| 헤미 | 한의약거리 | 초록 | 패턴 칸 2개 힌트 |
| 인도 | 인동시장 | 라벤더 | 첫·마지막 사건 힌트 |

### 현장 QR 코드 (장소 부착용)

| 장소 | QR 코드 값 |
|------|-----------|
| 소제동 | `DTQR-SOJEDOM-2025` |
| 중앙시장 | `DTQR-JUNGANG-2025` |
| 한의약거리 | `DTQR-HEREDI-2025` |
| 인동시장 | `DTQR-INDONG-2025` |

## 3. 기술 구성

| 영역 | 구성 |
|------|------|
| 프런트엔드 | Vue 3, Vite, JavaScript |
| 라우팅 | vue-router 4 (해시 기반) |
| QR 스캔 | jsQR (카메라 프레임 디코딩) |
| 상태 저장 | reactive() + localStorage (새로고침 유지) |
| 백엔드 | Python 3.12, FastAPI, Uvicorn |
| 캐릭터 | 인라인 SVG + CSS 애니메이션 (외부 이미지 없음) |

데이터베이스, 지도 제공업체, AI 서비스는 현재 연결하지 않습니다.

## 5. 로컬 실행

### 준비

- Node.js 24.x 권장 (22.12 이상 가능)
- Python 3.12
- uv

### 프런트엔드

```bash
cd frontend
npm ci
npm run dev
```

기본 접속 주소: `http://localhost:5173`

### 백엔드

```bash
cd backend
uv sync --frozen --group dev
uv run uvicorn app.main:app --reload
```

상태 확인: `http://127.0.0.1:8000/health`

## 6. 시연 방법

발표장에서 GPS·QR 없이 전체 흐름을 보여줄 수 있습니다.

1. `http://localhost:5173` 접속 → **탐험 시작**
2. 지도에서 **소제동 핀** 클릭 → **탐험 시작**
3. 이야기 4단계 클릭 → **탐험 시작 (시연)**
4. 카드 6장 뒤집어 3쌍 매칭
5. 소조 교감 3단계 → (조용히/기억/약속)
6. 보상 화면 → 도감에서 소조 확인
7. **QR 체크인**: 장소 도착 화면의 **"스캔"** 버튼
   → "시연용 코드 직접 입력" 토글 → **소제동** 버튼
8. 각성 연출 → **방문 카드 만들기** → 공유

중앙시장·한의약거리·인동시장도 동일한 흐름으로 시연 가능합니다.

**초기화**: 내 탐험 기록 화면 하단 "처음부터 다시 시작"
