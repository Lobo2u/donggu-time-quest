# 동구 타임퀘스트 (Donggu Time Quest)

## 📖 프로젝트 설명
동구 타임퀘스트는 시간 기반의 인터랙티브 퀘스트 게임/애플리케이션입니다.

## ✨ 주요 기능
- 시간 기반 퀘스트 시스템
- 사용자 진행도 추적
- 인터랙티브한 게임플레이

## 🛠️ 기술 스택
- Node.js / JavaScript
- React (프론트엔드)
- Express.js (백엔드)

## 📦 설치 및 실행

```bash
# 저장소 클론
git clone https://github.com/Lobo2u/donggu-time-quest.git
cd donggu-time-quest

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 실행
npm start
```
