# 퀘스트 기획

출처를 확인한 장소·기록을 바탕으로 퀘스트를 기획하는 폴더입니다.

---

## 구현된 퀘스트 (v1)

현재 4개 장소의 퀘스트가 구현되어 있습니다. 미션 시나리오·캐릭터는 모두 **창작**이며, 실제 역사와 혼동되지 않도록 게임 화면에서 구분 표기합니다.

### 소제동 — 흩어진 기억을 맞춰라

- **미션 방식**: 카드 뒤집기 기억 맞추기 (3쌍 6장)
- **시간 친구**: 소조 (기억을 지키는 빛의 조각 / 청록)
- **능력**: 기억 현상 — 카드 1장 잠깐 공개 / 각성 후 2장
- **교감 포인트**: 조용히 다가가기 → 기억을 같이 보자고 하기 → 항상 함께하자고 약속하기
- **실제 장소 안내**: 1930년대 철도 관사 건물 보존, 역사 문화 마을
- **QR 코드**: `DTQR-SOJEDOM-2025`

### 중앙시장 — 시장 주문을 기억하라

- **미션 방식**: 아이템 4개 순서 암기 후 재현
- **시간 친구**: 중자 (시장 골목의 이야기꾼 / 오렌지)
- **능력**: 시장 기억 — 첫 번째 아이템 힌트 / 각성 후 1·2번째
- **교감 포인트**: 크게 같이 탐험하자고 외치기 → 열심히 듣고 따라 말해보기 → 앞으로 같이 다니자고 하기
- **실제 장소 안내**: 1960년대부터 이어진 전통 시장, 다양한 먹거리
- **QR 코드**: `DTQR-JUNGANG-2025`

### 한의약거리 — 빛의 패턴을 기억하라

- **미션 방식**: 3×3 격자에서 4칸 패턴 기억 후 재현, 3라운드
- **시간 친구**: 헤미 (약재 골목의 빛의 친구 / 초록)
- **능력**: 빛 기억 — 패턴 칸 1개 힌트 / 각성 후 2개
- **교감 포인트**: 천천히 조용히 따라가기 → 같은 패턴을 손가락으로 따라 그리기 → 같이 이 골목의 기억을 지켜나가자
- **실제 장소 안내**: 전통 약재 상점 밀집, 한의학 문화
- **QR 코드**: `DTQR-HEREDI-2025`

### 인동시장 — 골목의 흐름을 복원하라

- **미션 방식**: 섞인 사건 4개를 시간 순서대로 클릭
- **시간 친구**: 인도 (골목 시간의 수호자 / 라벤더)
- **능력**: 시간 정렬 — 첫 번째 사건 힌트 / 각성 후 첫·마지막 사건
- **교감 포인트**: 조용히 무엇을 하냐고 물어보기 → 같이 기록하고 싶다고 하기 → 같이 기록하고 더 많은 곳을 탐험하자
- **실제 장소 안내**: 지역 주민 생활과 밀접한 소규모 전통 시장
- **QR 코드**: `DTQR-INDONG-2025`

## 기본 원칙

- 실제 역사적 주장, 게임을 위한 창작 연출, 미검증 아이디어를 구분합니다.
- 미션은 게임 화면 안에서 단서를 제공하며, 사유지 출입·구매·직원 대화를 필수 조건으로 만들지 않습니다.
- 오답 시 성격 기반 힌트를 제공하고 재시도할 수 있습니다. 무작위 확률로 반복하게 만들지 않습니다.
- 출입 제한 구역 접근, 위험한 촬영, 타인 얼굴·개인정보 수집을 유도하지 않습니다.
