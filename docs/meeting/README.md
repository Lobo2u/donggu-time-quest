# 회의 기록

정기 회의는 목요일입니다. 시간·장소·온라인 링크는 팀에서 별도로 정하고, 참석자가 확인할 수 있는 곳에 공유합니다.

---

## 주요 결정 사항 (요약)

| 날짜 | 결정 |
|------|------|
| 10월 초 | 기술 스택: Vue 3 + Vite + FastAPI 확정 |
| 10월 중순 | 게임 콘셉트: 포켓몬 스타일 시간 친구 수집으로 확정 |
| 10월 중순 | 대상 장소: 소제동·중앙시장·한의약거리·인동시장 4곳 |
| 10월 말 | 현장 동기 강화: QR 체크인 → 버디 각성 → SNS 공유 카드 구조 채택 |
| 10월 말 | 해커톤 목표: 관광객 유치 (지역문제 해결형 창업) |

---

## 사용 방법

- 파일명: `YYYY-MM-DD-회의주제.md`
- 회의 전 논의할 질문과 검토할 자료를 적습니다.
- 회의 후 결정, 보류, 담당자, 기한을 분리합니다.
- 제안과 확정 사항을 구분하고, 변경한 결정에는 이유와 이전 기록 링크를 남깁니다.
- 연락처, 비밀번호, 접근 토큰, 개인정보가 포함된 회의 링크는 공개 저장소에 올리지 않습니다.
