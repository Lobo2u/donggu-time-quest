# 시장활성화 앱 화면 설계 (컨펌용)

동구 TIME QUEST에 시장활성화(지역화폐 연계 포인트) 흐름을 합친 화면 설계입니다.
레이아웃은 지역화폐 앱 "그리고"를 참고해 좌우를 반전해 구성했습니다.

- 디자인 캔버스: https://claude.ai/artifact/BTchCXsjj51aidgZgZUa5k (작성자가 공유해야 열람 가능)
- 원본 파일: [`screens/`](./screens) — 화면별 `.dc.html`과 배치 정보 `canvas.json`
  (캐릭터 이미지는 캔버스에 업로드된 파일이라 이 폴더만으로는 보이지 않습니다)

## 핵심: 보상 = 대전사랑카드 연계 포인트

- 1포인트 = 1원, 현금성 포인트
- 다음 결제 때 **포인트가 먼저 자동 차감**되고, 모자란 금액만 충전액에서 빠짐
- 환불 불가
- 쿠폰 대신 포인트로 한 이유: 지자체가 지역사랑상품권 등 로컬 상권에 예산을 투입하고 있어(2026년 국비 1조 1,500억 원) 연계 명분이 분명함

## 화면 구성

| 번호 | 화면 | 내용 |
|---|---|---|
| 01 | 홈 · 현재 목표 | 라임 헤더(왼쪽 햄버거, 오른쪽 게임 제목) → 캐릭터 대사 → 현재 목표 카드 → 등급·힌트 게이지·나의 포인트 카드 → "게임 시작!" 원형 버튼 → 지금 할 수 있는 체험(장소 원 4개 + 체험 카드) |
| 02 | 탐험 지도 | 기울인 미니 지도, 로우폴리 건물, 장소 팻말이 떠 있는 형태. 완료=연두, 현재 목표=주황, 잠김=밝은 회색 |
| 03 | 장소 도착 · 미션 | 도착했을 때만 진입. "뒤로가기", 미니게임 시작 / QR 아이콘 + "캐릭터 강화" |
| 04 | 미니게임 | 일시중지 버튼, 힌트 게이지 |
| 04-1 | 게임 일시중지 | "일시중지!" · 계속하기 · 다시 시작 · 소리 설정 · 홈으로 (게임 중에는 햄버거 메뉴 없음) |
| 05 | 보상 | 스탬프 + 포인트 적립 |
| 06 | 시간 친구 도감 | 강화 없음(밝은 회색) / 강화 완료, 미발견은 ??? |
| 07 | 나의 포인트 | 잔액, 내역, 차감 규칙 안내 |
| 08 | 햄버거 메뉴 | 프로필 "[이름] · 감 등급", 탐험/수집/포인트, 고객센터. 운영자 메뉴 없음 |
| 08-1 | 등급 혜택 | 현재 등급과 다음 등급까지 남은 스탬프, 등급별 혜택 |

## 용어 변경

| 기존 | 변경 |
|---|---|
| 각성 / QR 각성 | 캐릭터 강화 (상태: 강화 없음 · 강화 완료) |
| 시간 조각 | 단서 조각 (힌트 게이지를 채움, 아이콘은 주황 원 안의 "?") |
| P | 포인트 |
| 내 ○○ | 나의 ○○ |
| 사장님 QR | 가게에 붙은 QR / 매장 QR |
| 캐릭터 대사 | 존댓말 |

## 등급 (제사상 과일, 대추가 최상위)

레벨 숫자(Lv.1~5)는 유지하고, 과일 아이콘으로 등급을 보여줍니다.

| 레벨 | 등급 | 혜택(안) |
|---|---|---|
| Lv.1 | 배 | 미션 포인트 기본 적립 · 힌트 게이지 3칸 |
| Lv.2 | 밤 | 미션 포인트 +[N]% · 힌트 게이지 4칸 |
| Lv.3 | 감 | 미션 포인트 +[N]% · 힌트 게이지 5칸 · 단서 조각이 더 자주 나타남 |
| Lv.4 | 사과 | 미션 포인트 +[N]% · 제휴 상점 등급 할인 · 시즌 코스 먼저 열림 |
| Lv.5 | 대추 | 미션 포인트 +[N]% · 완주 추첨 응모권 2배 · 도감 금테 배지 |

| 주요 버튼(파랑) | `#4A5FE7` |
| 현재 목표 · 힌트(주황) | `#FF9F1C` / 연한 주황 `#FFF1D6` |
| 본문 / 보조 글자 | `#222222` / `#6B6B6B` |
| 잠김 · 비활성 | 배경 `#F0F0F0`, 글자 `#8A8A8A` |

## 컨펌이 필요한 점

- 등급 혜택의 [N]% 수치, 다음 등급까지 필요한 스탬프 수
- 대전사랑카드 포인트 연동 방식(운영사 API 협의 필요), 포인트 유효기간
- 고객센터 전화번호
- 실제 건물 배치: 지도 건물은 아직 실제 위치와 다릅니다 (실측 자료 필요)
- 캐릭터 표정/포즈 추가 이미지
