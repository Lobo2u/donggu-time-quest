# 회의 기록

정기 회의는 목요일입니다. 시간·장소·온라인 링크는 팀에서 별도로 정하고, 참석자가 확인할 수 있는 곳에 공유합니다.

## 사용 방법

- 파일명: `YYYY-MM-DD-회의주제.md`
- 회의 전 논의할 질문과 검토할 자료를 적습니다.
- 회의 후 결정, 보류, 담당자, 기한을 분리합니다.
- 제안과 확정 사항을 구분하고, 변경한 결정에는 이유와 이전 기록 링크를 남깁니다.
- 주연이 기록을 맡되 모든 팀원이 내용을 확인합니다.
- 연락처, 비밀번호, 접근 토큰, 개인정보가 포함된 회의 링크는 공개 저장소에 올리지 않습니다.

## 회의록 템플릿

```markdown
# YYYY-MM-DD 회의

- 참석자:
- 목적:
- 검토 자료:

## 논의
- 안건:
- 확인한 근거:
- 의견과 대안:

## 결정
- 결정 내용:
- 이유:
- 영향받는 문서 또는 작업:

## 보류·확인 필요
- 질문:
- 추가 조사 방법:

## 할 일
| 작업 | 담당자 | 기한 | 완료 기준 | 관련 이슈·PR |
| --- | --- | --- | --- | --- |

## 다음 회의
- 날짜·시간:
- 준비할 자료:
```

초기 회의에서는 문제 정의, 장소 2~3곳의 선정 기준, MVP 범위, 사용자 검증 방법을 먼저 맞춥니다. 지도 제공자, AI 연동, 데이터 구조는 필요와 근거를 확인한 뒤 결정합니다.
